# Передача проекта — 23 сентября 2026

Проект: веб-ремейк Hextris в `hextris-remake`. Рабочая ветка: `codex/hextris-remake`. По просьбе пользователя работу остановили после реализации этапа 7; **не пушили**. Этот файл и весь код сохранены коммитами в этой ветке.

## Что сделано

- Этапы 1–3: бесконечные 75-секундные циклы Settle/Build/Pressure/Release, плавные потолки скорости и частоты, детерминированный бюджет угроз, честные предупреждения, подготовленная первая волна после 1,2 секунды, бонусы в допустимых окнах каждые 35–50 активных секунд.
- Этап 4: таймлайны вступления, полёта бонуса (90 мс удержание + 800 мс полёт), замены, активации и пояснений аномалий; безопасные запасные подписи для неизвестных ID.
- Этап 5: ограниченные по времени/количеству эффекты, раздельные характеры SLOW/PULSE/CLEANSE/COLOR BREAK, подсказки аномалий, reduced motion.
- Этап 6: шесть Canvas-слоёв, матовая сборка хаба, направляющие первой волны, читаемый падающий бонус, локальные удары/фрагменты, корректные DRIFT/INERTIA-маркеры и перелёт бонуса. Несколько замечаний независимого ревью исправлены; итоговый код принят.
- Этап 7: постоянный HUD-слот с названием, описанием и клавишей «ПРОБЕЛ»; счёт/множитель/фаза сверху, предупреждения возле затронутых сторон, устойчивые DOM-узлы и фокус, одно голосовое объявление для двойного предупреждения. Коммит реализации: `cf673d5`. **Независимое ревью этапа 7 ещё не проводилось** из-за запрошенной остановки.

Одобренный дизайн: `docs/superpowers/specs/2026-09-21-hextris-premium-arcade-redesign.md`. Подробный девятиэтапный план: `docs/superpowers/plans/2026-09-21-hextris-premium-arcade-redesign.md`. Визуальный принцип — матовый графит, приятные цвета, минимализм с выразительной физикой; никакого неона, шаблонного dashboard/UI, магазина, аккаунтов или постоянной прокачки.

## Перенос на другой ПК

На этом ПК из папки проекта отправить ветку:

```powershell
git push origin codex/hextris-remake
```

На другом ПК получить её (`git fetch origin`, затем `git switch codex/hextris-remake`; если локальной ветки ещё нет, `git switch -c codex/hextris-remake --track origin/codex/hextris-remake`). В папке проекта выполнить:

```powershell
npm.cmd ci
npm.cmd run test:run
npm.cmd run dev -- --host 127.0.0.1
```

Открыть `http://127.0.0.1:5173/`. В PowerShell использовать именно `npm.cmd`, чтобы не упереться в запрет запуска `npm.ps1`. Не добавлять `\` в конце адреса хоста. Если переносится не Git-ветка, а целая папка, `node_modules` и `dist` можно не копировать — `npm.cmd ci` и `npm.cmd run build` восстановят их.
